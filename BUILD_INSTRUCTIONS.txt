================================================================
  ARRAYVATOR — ИНСТРУКЦИЯ ПО СБОРКЕ ПОРТАТИВНОЙ ВЕРСИИ
================================================================

Этот файл описывает, как собрать портативную версию ArrayVator
из исходников. Портативная версия — это одна папка со всеми
библиотеками внутри. Её можно копировать на любой ПК, где нет
Python, и всё будет работать.


----------------------------------------------------------------
1. ЧТО ЭТО ТАКОЕ
----------------------------------------------------------------

Портативная сборка ArrayVator содержит три компонента:

    ArrayVator.exe   — редактор языка (GUI)
    runner.exe       — интерпретатор .arrv программ
    compiler.exe     — компилятор .arrv → .exe

Все три — со всеми зависимостями внутри папки _internal/.

Готовую папку ArrayVator_Portable/ можно:
    • Копировать на флешку
    • Передавать коллегам
    • Запускать на ПК без Python


----------------------------------------------------------------
2. ТРЕБОВАНИЯ (один раз на сборочной машине)
----------------------------------------------------------------

Операционная система:
    Windows 10 или 11 (64-bit)

Python:
    Python 3.10+ (рекомендуется 3.14)
    При установке отметьте "Add Python to PATH"
    Скачать: https://www.python.org/downloads/

Библиотеки Python:
    Откройте cmd и выполните:

    pip install pyinstaller
    pip install duckdb
    pip install python-calamine
    pip install pyexcelerate
    pip install openpyxl
    pip install matplotlib
    pip install plotly

    Одной строкой:
    
    pip install pyinstaller duckdb python-calamine pyexcelerate openpyxl matplotlib plotly


UPX (опционально, но рекомендуется):
    UPX сжимает библиотеки, уменьшая итоговый размер на 30-40%.
    Скачать: https://github.com/upx/upx/releases
    Файл:   upx-5.2.1-win64.zip
    Распаковать в: C:\upx\  (там должен быть upx.exe)


----------------------------------------------------------------
3. ПРОВЕРКА ОКРУЖЕНИЯ
----------------------------------------------------------------

Перед сборкой убедитесь, что всё установлено:

    python --version
        Должно показать: Python 3.14.x (или 3.13, 3.12)

    python -c "import duckdb; print(duckdb.__version__)"
        Должно показать: 1.5.5 (или другую версию)

    python -c "import pyinstaller; print(pyinstaller.__version__)"
        Должно показать версию PyInstaller

    C:\upx\upx.exe --version
        Должно показать: upx 5.2.1  (если UPX установлен)

Если все команды работают — можно собирать.


----------------------------------------------------------------
4. СБОРКА
----------------------------------------------------------------

Откройте cmd, перейдите в папку проекта:

    cd C:\Users\kos\Documents\0\Arrayvator

Запустите сборку:

    python build_portable.py

Что происходит:
    1. Проверка Python и PyInstaller
    2. Проверка библиотек
    3. Поиск UPX
    4. Сборка runner      (~1-3 минуты)
    5. Сборка compiler    (~1-2 минуты)
    6. Сборка arrayvator  (~1-2 минуты)
    7. Сборка портативной папки

Итого: 3-6 минут (зависит от скорости ПК).


----------------------------------------------------------------
5. ЧТО ПОЛУЧИТСЯ
----------------------------------------------------------------

В корне проекта появится папка:

    ArrayVator_Portable\
    ├── ArrayVator.exe        ← ЗАПУСКАТЬ ЭТОТ ФАЙЛ
    ├── _internal\            ← библиотеки редактора
    ├── runner\
    │   ├── runner.exe        ← интерпретатор
    │   └── _internal\
    └── compiler\
        ├── compiler.exe      ← компилятор
        └── _internal\

Также появятся вспомогательные папки:

    dist\     — промежуточные сборки (можно удалить)
    build\    — временные файлы (можно удалить)

Размер ArrayVator_Portable/:
    Без UPX:  ~210 МБ
    С UPX:    ~140-160 МБ


----------------------------------------------------------------
6. ПРОВЕРКА РАБОТЫ
----------------------------------------------------------------

Тест 1. Запуск редактора

    Откройте ArrayVator_Portable\ArrayVator.exe
    Должно открыться окно "ArrayVator Editor"

Тест 2. Выполнение кода

    В редакторе нажмите Ctrl+N (новый файл)
    Напишите:
        m = ["A", "B"; 1, 2; 3, 4]
        print(m)
    Нажмите F5

    В консоли должно появиться:
        A  B
        1  2
        3  4

Тест 3. BigData (DuckDB)

    В редакторе напишите:
        m = ["ID", "Имя"; 1, "Аня"]
        SaveCSV(m, "test.csv")
        bd = OpenCSV("test.csv", BigData)
        print(type(bd))

    Нажмите F5
    В консоли должно быть:
        duckdb

    Если ошибка "DuckDB не установлен" — см. раздел 8.

Тест 4. График

    В редакторе напишите:
        m = ["Отдел", "Зарплата"; "IT", 100; "HR", 80]
        chart(bar, m[:, "Отдел"], m[:, "Зарплата"])
    Нажмите F5

    Должно открыться окно с графиком.

Тест 5. Компилятор

    В редакторе нажмите Ctrl+E (или кнопку "EXE")
    Должно открыться окно "ArrayVator Compiler"
    Заголовок на английском, без упоминаний PyInstaller

    Выберите .arrv, папку, имя — нажмите "Build EXE"
    Через 1-2 секунды получите папку program/ с program.exe


----------------------------------------------------------------
7. ПЕРЕНОС НА ДРУГОЙ ПК
----------------------------------------------------------------

Скопируйте ВСЮ папку ArrayVator_Portable/ целиком:

    На флешку:  D:\ArrayVator_Portable\
    На рабочий стол:  C:\Users\User\Desktop\ArrayVator_Portable\

ВАЖНО: копируйте ВСЮ папку, а не отдельные файлы.
       Иначе не найдутся библиотеки в _internal/.

На целевом ПК:
    • Python устанавливать НЕ надо
    • pip install делать НЕ надо
    • Ничего дополнительно настраивать не надо

Просто:
    1. Откройте ArrayVator_Portable\
    2. Двойной клик по ArrayVator.exe
    3. Готово


----------------------------------------------------------------
8. ЧАСТЫЕ ОШИБКИ
----------------------------------------------------------------

Ошибка: "python.exe не найден"

    Причина: Python не установлен или не в PATH.
    Решение:
        • Переустановите Python с галочкой "Add to PATH"
        • Или добавьте вручную через "Изменение переменных среды"


Ошибка: "PyInstaller не установлен"

    Причина: PyInstaller не установлен.
    Решение:
        pip install pyinstaller


Ошибка: "❌ duckdb — не установлен"

    Причина: не установлен duckdb.
    Решение:
        pip install duckdb


Ошибка после сборки: "DuckDB не установлен" при запуске .arrv

    Причина: PyInstaller не захватил модуль.
    Решение:
        • Убедитесь, что в build_portable.py для runner стоит:
          '--collect-all', 'duckdb'
        • Убедитесь, что в runner.py вверху есть:
          try:
              import duckdb
          except ImportError:
              pass
        • Пересоберите: python build_portable.py


Ошибка: "Runtime folder not found" в компиляторе

    Причина: компилятор не нашёл папку runner/.
    Решение:
        • В портативной сборке runner/ лежит рядом с compiler/
        • Проверьте структуру:
          ArrayVator_Portable\compiler\compiler.exe
          ArrayVator_Portable\runner\runner.exe
        • Если структура битая — пересоберите


Ошибка: UPX ломает библиотеки

    Симптом: сборка падает на этапе UPX-сжатия,
             или exe не запускается после сборки
    Решение:
        • Откройте build_portable.py
        • Найдите строку: UPX_FLAGS = _build_upx_flags()
        • Замените на:    UPX_FLAGS = []
        • Пересоберите

    Или убедитесь, что в _build_upx_flags() есть:
        '--upx-exclude', '*.pyd',
        '--upx-exclude', '*.dll',
        '--upx-exclude', '*.exe',


Ошибка: в портативной сборке старый интерфейс

    Причина: compiler.exe / ArrayVator.exe собраны из старых
             исходников.
    Решение:
        • Проверьте, что вы сохранили изменения в compiler_gui.py
          и/или main.py
        • Пересоберите: python build_portable.py


Ошибка: антивирус блокирует ArrayVator.exe

    Причина: PyInstaller-сборки иногда ложно срабатывают.
    Решение:
        • Добавьте папку ArrayVator_Portable/ в исключения
        • Или отключите UPX (см. выше) — тогда ложных
          срабатываний почти не будет


----------------------------------------------------------------
9. ОБНОВЛЕНИЕ ПОСЛЕ ПРАВОК
----------------------------------------------------------------

Если вы что-то изменили в исходниках:

    main.py           → меняет редактор
    compiler_gui.py   → меняет компилятор
    runner.py         → меняет интерпретатор
    любой модуль в     → меняет всё
      parser/, ast_nodes/,
      operators/, runtime/,
      syntax/, errors/

После ЛЮБЫХ правок:

    1. Сохраните файлы
    2. Запустите:  python build_portable.py
    3. Дождитесь окончания
    4. Папка ArrayVator_Portable/ пересоберётся

Время полной пересборки: 3-6 минут.

Можно собирать только один компонент — отредактируйте
список components в build_portable.py:

    components = [
        ("runner",     "runner.py",       RUNNER_FLAGS),
        # ("compiler",   "compiler_gui.py", COMPILER_FLAGS),
        # ("arrayvator", "main.py",         ARRAYVATOR_FLAGS),
    ]


----------------------------------------------------------------
10. ОЧИСТКА
----------------------------------------------------------------

После успешной сборки можно удалить:

    dist\      — промежуточные сборки (~400 МБ)
    build\     — временные файлы (~200 МБ)

Остаётся только:

    ArrayVator_Portable\   — 140-210 МБ

Всё, что нужно пользователю, — внутри неё.
