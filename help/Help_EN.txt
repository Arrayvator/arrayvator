================================================================
ARRAYVATOR — A DATA PROCESSING LANGUAGE
================================================================

WHAT IT IS
----------------------------------------------------------------
ArrayVator is a programming language for processing tabular
data. It was built for analysts, economists, marketers,
accountants, researchers, and everyone who works with tables:
Excel, CSV, Parquet, SQLite databases.

Instead of complex code and dozens of libraries — a single,
readable language where every operation reads like an
ordinary sentence:

    m = filterif(m[:, "Department"] == "IT")
    m = sort(m[:, "Salary"], ZA)
    m = addcolumn(m, "Tax", m[:, "Salary"] * 0.13)

This is not Python. Not R. Not SQL. This is a separate language
purpose-built so that a person without a programming background
can learn it in a single evening.

----------------------------------------------------------------
WHY IT EXISTS
----------------------------------------------------------------
• Process tables without Excel and without VBA.
• Do data analysis without Python and without pandas.
• Build pivot tables without Excel's pivot tables.
• Build charts without matplotlib.
• Produce reports without Word and without layout tools.
• Compile a finished program into a .exe and hand it to a
  colleague with no installation required.

One file with code — and the entire analysis logic is in your
hands. No dependencies, no version conflicts.

----------------------------------------------------------------
WHAT IS BUILT INTO THE LANGUAGE
----------------------------------------------------------------
More than 300 functions. Everything an analyst needs —
out of the box:

• Filtering, sorting, removing duplicates.
• Grouping, aggregation, pivot / unpivot tables.
• Conditional aggregates: sumif, countif, avgif, minif, maxif.
• Window functions: rownumber, rank, lag, lead, winsum.
• ABC analysis, Pareto analysis, anomaly detection
  (iqr, zscore, percentile).
• Dates: year, month, day, adddays, datetrunc, calendar.
• Text: trim, clean, split, replacetext, deletetext.
• None handling: isnone, fillna, dropna, coalesce, noneif.
• SQL-like operations: join, groupby, having.
• Files: Excel, CSV, TXT, Parquet, SQLite.
• BigData mode on DuckDB: up to a billion rows, ~50 MB RAM.
• Charts: bar, line, pie, hist, scatter, box, heatmap, pair.
• HTML reports with interactive Plotly charts.
• Matrix ↔ DuckDB conversion in a single line.

----------------------------------------------------------------
THE MAIN IDEA — READABILITY
----------------------------------------------------------------
ArrayVator is built on a simple principle: code should be
understandable by a human, not only by a machine.

    m = deleteif(m[:, "Department"] == "IT")

Reads in plain English: "delete rows where Department equals IT".
No braces, no indices, no commas — just a phrase.

Function names are short, meaningful, in English:
filterif, sort, groupby, sumif, vlookup, transpose.
You don't have to memorize them — the editor suggests them.

----------------------------------------------------------------
SMART AUTOCOMPLETE
----------------------------------------------------------------
The editor understands what you're typing and suggests.

Start typing "fil" — the editor suggests filterif.
Type "впр" (Russian alias for VLOOKUP) — the editor suggests vlookup.
Type "суммапо" — the editor suggests sumif.

Autocomplete works:
• by partial function name (fil → filterif);
• by Russian aliases (впр → vlookup, сводная → pivot);
• by the first letter;
• with arrow-key navigation ↑ ↓;
• with insertion via Tab or Enter.

The candidate list appears right under the cursor — just like
in modern IDEs. Nothing has to be memorized.

----------------------------------------------------------------
LIVE HELP WITH EXAMPLES
----------------------------------------------------------------
On the right side of the editor — a live help panel.
Click a function name in your code and you'll see:

• SYNTAX — the exact call format.
• DESCRIPTION — what the function does.
• EXAMPLE — how to call it.
• MATRIX EXAMPLE — concrete input, code and output.

Help updates instantly on click. No switching windows,
no Googling. Everything — right next to your code.

If a function doesn't exist — the editor suggests similar
ones and hints at what you might have meant.

----------------------------------------------------------------
POWERFUL ERROR HANDLING WITH HINTS
----------------------------------------------------------------
Errors in ArrayVator are not dry messages — they are full
explanations. Every error includes:

• What's wrong (in plain language).
• Where exactly (line and column, with a ^ pointer).
• How to fix it (a concrete example of correct code).
• Why it's this way (an explanation of the language's logic).

Example error message:

    ❌ Error (line 3):
      if x = 5 then

    In the condition '=' (assignment) is used,
    but '==' (comparison) is required.

    Incorrect: if x = 5 then
    Correct:   if x == 5 then

    💡 '='  — assigns a value.
       '==' — compares values.

Plus — automatic hints:
• "Did you mean filterif?"
• "Missing closing parenthesis ')' — add it at the end."
• "The keyword 'then' is required after the if condition."

Errors are available in two languages — Russian and English —
switchable with a single setting.

----------------------------------------------------------------
BUILD .EXE IN TWO CLICKS
----------------------------------------------------------------
The signature feature of ArrayVator: you can turn your script
into a standalone .exe program and hand it to a colleague —
no Python install, no library install, no configuration.

How it works:

1. Write code in the ArrayVator editor.
2. Click "Export to EXE".
3. Set the program name — for example, MyReport.exe.
4. Get a folder with the .exe and all libraries.

Your colleague double-clicks the .exe — and it just works.
No installs. No dependencies. Just a file.

The compiler picks the right runner automatically:

• If the code only has tables and math — a compact MINIMAL
  runner is built.
• If Excel or DuckDB is used — a DATA runner is built.
• If charts or reports are used — a FULL runner is built.

You don't have to think about this — the compiler chooses.

----------------------------------------------------------------
WHAT THE EDITOR DOES
----------------------------------------------------------------
ArrayVator Editor is a full development environment:

• Syntax highlighting (keywords, functions, variables,
  strings, numbers, comments — each in its own color).
• Line numbers.
• Find and replace (case-sensitive and case-insensitive).
• Built-in output console.
• Working folder — next to the editor.
• Auto-save of settings.
• Dark and light themes.
• Russian and English interface.
• Configurable fonts and highlight palette.
• Help panel that updates on click.
• Autocomplete with aliases.
• Error handling with human-readable hints.

All of this — in a single window. No external dependencies.

----------------------------------------------------------------
WHO THIS LANGUAGE IS FOR
----------------------------------------------------------------
• Analyst — quickly count, group, plot.
• Economist — build summaries by department and quarter.
• Marketer — run ABC analysis and find anomalies.
• Accountant — process exports from Excel or accounting systems.
• Researcher — clean data and compute statistics.
• Student — learn tabular work without Python.
• Manager — produce a report and pass it to colleagues.

ArrayVator is a language for people who work with data
but don't want to spend months learning Python and pandas.

----------------------------------------------------------------
WHAT THE LANGUAGE DOESN'T HAVE (AND NEVER WILL)
----------------------------------------------------------------
• Classes, inheritance, OOP.
• Lambdas and functional programming.
• Imports and package installs.
• Dependencies on external libraries (except BigData mode).
• Complex syntax for the sake of syntax.

The language is deliberately simple. Everything an analyst
doesn't need — has been removed.

----------------------------------------------------------------

✔ One readable language instead of ten libraries.
✔ 300+ built-in functions for data analysis.
✔ Smart autocomplete, including Russian aliases.
✔ Live help with examples right in the editor.
✔ Clear errors with hints and code examples.
✔ Build .exe in two clicks.
✔ Work with a billion rows via DuckDB.
✔ Charts and HTML reports out of the box.
✔ No dependencies when passing code to colleagues.

Simple. Readable. Fast. Yours.

# ============================================================
# COMPLETE REFERENCE FOR THE ARRAYVATOR LANGUAGE
# ============================================================
# For beginners. Everything as detailed and clear as possible.
# Each function: purpose, syntax, example, output.
#
# IMPORTANT TERMS USED IN THIS REFERENCE:
#
#   Scalar — a single value. One number, one text string,
#            one true/false, one None.
#            For example: 5, "Anna", true, None — all of these are scalars.
#
#   Vector — one row of values or one column of values.
#            Always one-dimensional (1D). Inside — only data,
#            without a header.
#            For example: [10, 20, 30] — a vector of 3 numbers.
#
#   Matrix — a table with a header and data (2D).
#            The first row — column headers.
#            The rest of the rows — data.
#            For example:
#            ["Name", "Age";
#             "Anna", 25;
#             "Bob", 30]
#
#   Slice — a part of a matrix (a column or a row).
#          For example: m[:, "Salary"] — the entire "Salary" column.
#          A vector is also a slice, but without a header.
#
#   by — a parameter that tells the function "count by groups".
#        Without by the function computes one number for the whole table.
#        With by — computes separately for each group (for example,
#        for each department or each class).
# ============================================================


# ============================================================
# 1. BASICS
# ============================================================

# ------------------------------------------------------------
# 1.1 What is None (empty value)
# ------------------------------------------------------------
# None is an empty value. Like an empty cell in Excel.
# It is always written the same way: None, none, NONE — these are the same.
# You cannot write: null, NULL, nan — those words do not exist in the language.
#
# Syntax: None
#
# Example:
x = None
print(x)
# Output: None
#
# Checking for emptiness:
r = isnone(None)
print(r)
# Output: True


# ------------------------------------------------------------
# 1.2 Boolean values (true / false)
# ------------------------------------------------------------
# true — true, false — false. Used in conditions.
#
# Syntax: true | false
#
# Example:
a = true
b = false
print(a, b)
# Output: True False


# ------------------------------------------------------------
# 1.3 Operators
# ------------------------------------------------------------
# Arithmetic:
#   +   addition
#   -   subtraction
#   *   multiplication
#   /   division (result is a floating-point number)
#   %   modulo (remainder)
#   ^   power
#   //  integer division
#
# Comparison:
#   ==  equal
#   !=  not equal
#   <   less than
#   >   greater than
#   <=  less than or equal
#   >=  greater than or equal
#
# Logic (written as WORDS, not symbols):
#   and  — AND
#   or   — OR
#   not  — NOT
#
# You CANNOT write: && || !  — those symbols do not exist in the language.
#
# Example:
x = 5 + 3
y = 10 / 4
z = 2 ^ 10
ok = (x > 5) and (y < 3)
print(x, y, z, ok)
# Output: 8 2.5 1024 True


# ============================================================
# 2. CONTROL STRUCTURES
# ============================================================

# ------------------------------------------------------------
# 2.1 if-then-else
# ------------------------------------------------------------
# If the condition is true — the block after then is executed.
# If not — the block after else (if present).
#
# Syntax:
#   if condition then { statements }
#   if condition then { statements } else { statements }
#
# Example:
x = 10
if x > 5 then { print("greater") } else { print("less") }
# Output: greater
#
# Example without else:
x = 3
if x > 5 then { print("greater") }
# Outputs nothing.


# ------------------------------------------------------------
# 2.2 for loop (repeat N times)
# ------------------------------------------------------------
# Executes the block for each number in the range.
# Both ends are inclusive: 1 to 5 — this is 1, 2, 3, 4, 5.
#
# Syntax:
#   for i = start to end do { statements }
#   for i = start to end step S do { statements }
#
# Example:
for i = 1 to 5 do { print(i) }
# Output:
# 1
# 2
# 3
# 4
# 5
#
# Reverse order:
for i = 5 to 1 do { print(i) }
# Output: 5 4 3 2 1 (each on a new line)
#
# With step 2:
for i = 1 to 10 step 2 do { print(i) }
# Output: 1 3 5 7 9
#
# With step -2:
for i = 10 to 1 step -2 do { print(i) }
# Output: 10 8 6 4 2
#
# IMPORTANT: you cannot write "for i = 2 to end".
# Inside a loop you cannot use end — it is unclear what "end" refers to.
# You must use length functions:
#   lenrow(m) — number of rows in matrix m
#   lencol(m) — number of columns
#   len(v)    — number of elements in vector v
#
# Example — iterating over employees:
m = ["Name", "Salary";
     "Anna", 50000;
     "Bob", 60000;
     "Eve", 55000]
print(m)
# Output:
# Name    Salary
# Anna    50000
# Bob     60000
# Eve     55000
#
for i = 2 to lenrow(m) do { print(m[i, 1], m[i, 2]) }
# Output:
# Anna 50000
# Bob 60000
# Eve 55000


# ------------------------------------------------------------
# 2.3 while loop (while condition is true)
# ------------------------------------------------------------
# Repeats the block while the condition is true.
#
# Syntax: while condition { statements }
#
# Example:
i = 1
while i <= 3 { print(i); i = i + 1 }
# Output: 1 2 3


# ------------------------------------------------------------
# 2.4 break (exit loop)
# ------------------------------------------------------------
# Terminates the loop early.
#
# Syntax: break
#
# Example:
for i = 1 to 100 do { if i > 3 then { break }; print(i) }
# Output: 1 2 3


# ------------------------------------------------------------
# 2.5 try/catch (error handling)
# ------------------------------------------------------------
# If an error occurs in the try block, control passes
# to the catch block. There you can inspect the error text.
#
# Syntax:
#   try { statements } catch { statements }
#   try { statements } catch (e) { statements }
#
# Example:
try { m = OpenCSV("no_such.csv") } catch { print("Error:", error) }
# Output: Error: File not found: no_such.csv
#
# Example with a variable:
try { m = OpenCSV("no_such.csv") } catch (e) { print("Caught:", e) }
# Output: Caught: File not found: no_such.csv


# ============================================================
# 3. CREATING DATA
# ============================================================

# ------------------------------------------------------------
# 3.1 matrix(R, C) — create a matrix
# ------------------------------------------------------------
# Creates a matrix of R rows by C columns.
# All cells are filled with None.
#
# Syntax: matrix(R, C)
#
# Example:
m = matrix(2, 3)
print(m)
# Output:
# None  None  None
# None  None  None


# ------------------------------------------------------------
# 3.2 vector(N) — create a vector
# ------------------------------------------------------------
# A vector is a single row of values.
# Creates a vector of N None elements.
#
# Syntax: vector(N)
#
# Example:
v = vector(4)
print(v)
# Output: [None, None, None, None]


# ------------------------------------------------------------
# 3.3 zeros / ones — zeros or ones
# ------------------------------------------------------------
# Syntax:
#   zeros(R, C)   — R×C matrix of zeros
#   zeros(N)      — vector of N zeros
#   ones(R, C)    — R×C matrix of ones
#   ones(N)       — vector of N ones
#
# Example:
m = zeros(2, 3)
print(m)
# Output:
# 0  0  0
# 0  0  0
#
v = ones(4)
print(v)
# Output: [1, 1, 1, 1]


# ------------------------------------------------------------
# 3.4 fill — fill with a value
# ------------------------------------------------------------
# Fills ALL cells with the given value.
#
# Syntax: fill(matrix, value)
#
# Example:
m = matrix(2, 2)
print(m)
# Output:
# None  None
# None  None
#
m = fill(m, 7)
print(m)
# Output:
# 7  7
# 7  7


# ------------------------------------------------------------
# 3.5 range / Number — sequence of numbers
# ------------------------------------------------------------
# Creates a sequence of numbers.
#
# Syntax:
#   range(N)                   — [1, 2, ..., N]
#   range(a:b)                 — [a, a+1, ..., b]
#   range(a:b, step S)         — with step S
#
# IMPORTANT: range works only in an assignment.
#
# Example:
m = matrix(5, 1)
print(m)
# Output:
# None
# None
# None
# None
# None
#
m[:, 1] = range(5)
print(m)
# Output:
# 1
# 2
# 3
# 4
# 5
#
m = matrix(5, 1)
print(m)
# Output:
# None
# None
# None
# None
# None
#
m[:, 1] = range(1:10, step 2)
print(m)
# Output:
# 1
# 3
# 5
# 7
# 9


# ------------------------------------------------------------
# 3.6 random — random numbers
# ------------------------------------------------------------
# Generates random numbers.
# Works ONLY in an assignment (not in print!).
#
# Syntax: random(start:end, precision)
#   start:end  — range (both ends inclusive)
#   precision  — 0 for integers, N for float with N decimal places
#
# Example:
x = random(0:10, 0)
print(x)
# Output: for example 7 (different each time)
#
m = matrix(2, 2)
print(m)
# Output:
# None  None
# None  None
#
m[all, all] = random(0:10, 0)
print(m)
# Output: for example
# 3  8
# 1  9
# ============================================================
# 4. INDEXING AND ASSIGNMENT
# ============================================================

# ------------------------------------------------------------
# 4.1 Index forms
# ------------------------------------------------------------
# An index is a way to access a cell, a row, or a column.
#
# Forms:
#   m[N, M]            — cell (row N, column M)
#   m[N, :]            — the whole row N
#   m[:, M]            — the whole column M
#   m[:, "Name"]       — the whole column by name
#   m[N:M, K:L]        — range (rows N..M, columns K..L)
#   m[last K, :]       — last K rows
#   m[:, last K]       — last K columns
#   m[end, :]          — last row
#   m[:, end]          — last column
#   m[:, end+1]        — a new column to the RIGHT of the last one
#
# Example:
m = ["Name", "Age", "Department";
     "Anna", 25, "IT";
     "Bob", 30, "HR";
     "Eve", 28, "IT"]
print(m)
# Output:
# Name    Age  Department
# Anna    25   IT
# Bob     30   HR
# Eve     28   IT
#
print(m[1, 1])
# Output: Anna
#
print(m[1, :])
# Output: ["Anna", 25, "IT"]
#
print(m[:, "Department"])
# Output: ["IT", "HR", "IT"]
#
print(m[1:2, 1:2])
# Output:
# Anna  25
# Bob   30
#
print(m[end, :])
# Output: ["Eve", 28, "IT"]
#
print(m[:, end])
# Output: ["IT", "HR", "IT"]
#
print(m[last 2, :])
# Output:
# Bob    30  HR
# Eve    28  IT


# ------------------------------------------------------------
# 4.2 Reading headers
# ------------------------------------------------------------
# m[0, :] — this is the vector of headers.
#
# Example:
m = ["Name", "Age"; "Anna", 25]
print(m)
# Output:
# Name  Age
# Anna  25
#
h = m[0, :]
print(h)
# Output: ["Name", "Age"]


# ------------------------------------------------------------
# 4.3 Assigning a single cell
# ------------------------------------------------------------
# Syntax: m[row, column] = value
#
# Example:
m = ["Name", "Salary";
     "Anna", 50000;
     "Bob", 60000]
print(m)
# Output:
# Name  Salary
# Anna  50000
# Bob   60000
#
m[1, 2] = 55000
print(m)
# Output:
# Name  Salary
# Anna  55000
# Bob   60000

# ------------------------------------------------------------
# 5.0 WHAT IS by (important to understand before the functions)
# ------------------------------------------------------------
# Take a table of employees:
m = ["Department", "Salary";
     "IT", 100;
     "HR", 200;
     "IT", 300]
print(m)
# Output:
# Department  Salary
# IT          100
# HR          200
# IT          300
#
# WITHOUT by — the function computes ONE number for the WHOLE table.
#   sum(m[:, "Salary"]) = 600
#
# WITH by — the function computes SEPARATELY for each group.
#   sum(m[:, "Salary"], by m[:, "Department"]) = [400, 200, 400]
#
#   What happened:
#     IT group: 100 + 300 = 400
#     HR group: 200 = 200
#   The result is a vector of 3 numbers, one for each
#   row of the table. For the row "IT" — the sum of its entire group.
#
# This is similar to pivot, but there is a difference:
#   pivot  — creates a NEW table (a pivot table), where groups are
#            rows or columns, and there is less data.
#   by     — leaves the table as is, but instead of one number
#            substitutes the number for the group for EACH row.
#            Often used in addcolumn.


# ------------------------------------------------------------
# 5.1 sum — sum
# ------------------------------------------------------------
# Syntax:
#   sum(slice)                    — single number
#   sum(slice, by m[:, "X"])      — vector by groups
#
# Example without by:
m = ["Department", "Salary";
     "IT", 100; "HR", 200; "IT", 300]
print(m)
# Output:
# Department  Salary
# IT          100
# HR          200
# IT          300
#
s = sum(m[:, "Salary"])
print(s)
# Output: 600
#
# Example with by — by groups:
r = sum(m[:, "Salary"], by m[:, "Department"])
print(r)
# Output: [400, 200, 400]
#
# Example — add the group sum into a column:
m = addcolumn(m, "Dept_Total", sum(m[:, "Salary"], by m[:, "Department"]))
print(m)
# Output:
# Department  Salary  Dept_Total
# IT          100     400
# HR          200     200
# IT          300     400

# ------------------------------------------------------------
# 8.3 vlookup — VLOOKUP analog
# ------------------------------------------------------------
# Searches for a value in ONE table and substitutes it into ANOTHER.
# Usually two tables:
#   • Lookup table — where the data is stored (ID → Department).
#   • Main table — where you need to substitute (list of employees).
#
# Mnemonic:
#   vlookup( where_to_look,  what_to_search,  what_to_return )
#            └── lookup ──┘  └── query ────┘  └── lookup ────┘
#
# Syntax: vlookup(where_to_look, what_to_search, what_to_return)
#
# Example — there is a department lookup table and a list of employees.
# We need to substitute the department name for each employee.
#
# Lookup table (table "lookup"):
lookup = ["Code", "Department";
          101, "IT";
          102, "HR";
          103, "Sales"]
print(lookup)
# Output:
# Code  Department
# 101   IT
# 102   HR
# 103   Sales
#
# Main table (table "employees"):
employees = ["Name", "Dept_Code";
             "Anna", 101;
             "Bob", 102;
             "Eve", 103]
print(employees)
# Output:
# Name    Dept_Code
# Anna    101
# Bob     102
# Eve     103
#
# Look at the employees BEFORE:
print(employees)
# Output:
# Name    Dept_Code
# Anna    101
# Bob     102
# Eve     103
#
# Substitute the department for each employee in a new column:
employees = addcolumn(
    employees,
    "Department",
    vlookup(lookup[:, "Code"], employees[:, "Dept_Code"], lookup[:, "Department"])
)
print(employees)
# Output:
# Name    Dept_Code  Department
# Anna    101        IT
# Bob     102        HR
# Eve     103        Sales
#
# How to read this:
#   1st argument: lookup[:, "Code"]           — where to look (key column)
#   2nd argument: employees[:, "Dept_Code"]   — what to look for (vector of values)
#   3rd argument: lookup[:, "Department"]     — what to return from the lookup
#
# If you look up a single value instead of a vector:
r = vlookup(lookup[:, "Code"], 102, lookup[:, "Department"])
print(r)
# Output: HR

# 14. GROUPING AND AGGREGATION
# ============================================================

# ------------------------------------------------------------
# 14.1 groupby — grouping
# ------------------------------------------------------------
# Creates a NEW table — one row per group.
#
# Syntax:
#   groupby(by m[:, "X"], agg sum(m[:, "Y"]))
#   groupby(by m[:, "X"], agg sum(...), avg(...), count())
#   groupby(by m[:, "X"], agg sum(...), having sum(...) > 100)
#
# Example:
m = ["Department", "Salary";
     "IT", 100;
     "HR", 200;
     "IT", 300]
print(m)
# Output:
# Department  Salary
# IT          100
# HR          200
# IT          300
#
r = groupby(by m[:, "Department"], agg sum(m[:, "Salary"]))
print(r)
# Output:
# Department  Sum_Salary
# IT          400
# HR          200
#
# Mnemonic: was 3 rows — became 2 groups.
#
# With having:
r = groupby(by m[:, "Department"], agg sum(m[:, "Salary"]),
            having sum(m[:, "Salary"]) > 300)
print(r)
# Output:
# Department  Sum_Salary
# IT          400


# ------------------------------------------------------------
# 14.2 groupagg — block aggregation
# ------------------------------------------------------------
# Walks the table, finds blocks (identical key values),
# inserts a total row after each block.
#
# Syntax: groupagg(key, value, agg [, name] [, fill|exact])
#
# Example:
m = ["Client", "Amount";
     "Anna", 100;
     "Anna", 200;
     "Bob", 300]
print(m)
# Output:
# Client  Amount
# Anna    100
# Anna    200
# Bob     300
#
r = groupagg(m[:, "Client"], m[:, "Amount"], sum, "TOTAL")
print(r)
# Output:
# Client  Amount
# Anna    100
# Anna    200
# TOTAL   300
# Bob     300
# TOTAL   300
#
# Modes:
#   fill  — empty values join the current block (default)
#   exact — each value is a separate block (even empty)


# ------------------------------------------------------------
# 14.3 pivot — pivot table
# ------------------------------------------------------------
# Syntax:
#   pivot(key, values, agg)                        — 3 arguments
#   pivot(row_key, col_key, values, agg)           — 4 arguments
#
# Example with 3 arguments:
m = ["Department", "Salary";
     "IT", 100;
     "HR", 200;
     "IT", 300]
print(m)
# Output:
# Department  Salary
# IT          100
# HR          200
# IT          300
#
r = pivot(m[:, "Department"], m[:, "Salary"], sum)
print(r)
# Output:
# Department  Value
# IT          400
# HR          200
#
# Example with 4 arguments:
m = ["Department", "Year", "Salary";
     "IT", 2024, 100;
     "IT", 2025, 300;
     "HR", 2024, 200]
print(m)
# Output:
# Department  Year  Salary
# IT          2024  100
# IT          2025  300
# HR          2024  200
#
r = pivot(m[:, "Department"], m[:, "Year"], m[:, "Salary"], sum)
print(r)
# Output:
# Department  2024  2025
# IT          100   300
# HR          200   None


# ------------------------------------------------------------
# 14.4 unpivot — from wide to long
# ------------------------------------------------------------
# Syntax: unpivot(slice, by slice [, names "Name1", "Name2"])
#
# Example:
m = ["Country", "2023", "2024";
     "USA", 100, 120;
     "UK", 200, 220]
print(m)
# Output:
# Country  2023  2024
# USA      100   120
# UK       200   220
#

# Country  Year  Population
# USA      2023  100
# USA      2024  120
# UK       2023  200
# UK       2024  220
