--------------------------------------------------------------------------------
0.1. Что такое ArrayVator
--------------------------------------------------------------------------------

ArrayVator — это язык программирования для работы с таблицами. Он похож на
Excel, но с настоящими циклами, условиями, функциями и возможностью
обрабатывать миллиарды строк (через BigData/DuckDB).

Таблица в ArrayVator называется МАТРИЦЕЙ. Первая строка матрицы — это
ЗАГОЛОВКИ СТОЛБЦОВ. Остальные строки — данные.

Главное правило языка:

    ВСЕ ФУНКЦИИ ВОЗВРАЩАЮТ ЗНАЧЕНИЕ.
    РЕЗУЛЬТАТ НУЖНО СОХРАНИТЬ В ПЕРЕМЕННУЮ.

Правильно:

    r = filterif(m[:, "Отдел"] == "IT")

Неправильно:

    filterif(m[:, "Отдел"] == "IT")

Если не сохранить результат — он потеряется.

Что есть в языке:

    ✅ Подсветка синтаксиса
    ✅ Автодополнение функций
    ✅ Встроенная справка по каждой функции
    ✅ Экспорт программы в EXE
    ✅ Работа с Excel, CSV, TXT, Parquet, SQLite
    ✅ Работа с 1 млрд строк (BigData)
    ✅ Встроенные графики и HTML-отчёты

--------------------------------------------------------------------------------

1. Скачайте установщик ArrayVator с сайта http://arrayvator.ru/

3. После установки откройте ArrayVator.
4. Перед вами появится окно редактора с пустым файлом.
5. Напишите первую программу:

7. В нижней панели появится вывод:

    Привет, ArrayVator!

--------------------------------------------------------------------------------
0.5. Как читать эту справку
--------------------------------------------------------------------------------

Для каждой функции приведено:

1. Назначение — зачем нужна функция, какую задачу решает.
2. Синтаксис — как правильно вызывать.
3. Пример — код, который можно сразу запустить.
4. Матрица до / после — как выглядели данные и как стали.
5. Вывод — что напечатается в панели вывода.
6. Важные замечания — что нельзя делать, какие есть подводные камни.

Примеры используют таблицу:

    m = ["Имя", "Отдел", "Зарплата";
         "Аня", "IT", 85000;
         "Боб", "HR", 65000;
         "Света", "IT", 95000;
         "Гоша", "Sales", 80000]

Матрица до:

    Имя    Отдел  Зарплата
    Аня    IT     85000
    Боб    HR     65000
    Света  IT     95000
    Гоша   Sales  80000


--------------------------------------------------------------------------------
0.6. Общие правила языка
--------------------------------------------------------------------------------

1. Регистронезависимость
   Язык полностью регистронезависимый. m = M, none = None = NONE,
   true = TRUE, sum = SUM. Это касается и переменных, и функций,
   и литералов.

2. Индексация с 1
   m[1, :] — это первая строка (заголовки).
   m[2, :] — первая строка данных.
   m[:, 1] — первый столбец.
   m[1, 1] — левая верхняя ячейка.

3. Заголовок
   Пишешь ИМЯ (в кавычках) — заголовок НЕ участвует.
   Пишешь НОМЕР — заголовок УЧАСТВУЕТ.
   Явный диапазон [3:end] — заголовок НЕ участвует.
   last N — последние N строк.
   all / : — все строки или столбцы.

4. = и ==
   =  — присваивание.
   == — сравнение.
   В if / while / when использовать = нельзя (ошибка).

5. Логические операторы
   and / or / not (не &&, ||, !).

6. Пустое значение
   Только None. Слова null и nan — ошибка.

--------------------------------------------------------------------------------
1.1. Типы данных
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Понять, какие значения можно хранить и как с ними работать.

ТИПЫ:

    integer   — целое: 42, -5, 1000
    float     — дробное: 3.14, -0.5, 2.0
    string    — строка: "Привет", 'Мир'
    boolean   — логическое: true, false
    None      — пустое (только с большой буквы, но регистр не важен)
    vector    — вектор (1D)
    matrix    — матрица (2D)
    datetime  — дата-время
    date      — дата
    time      — время
    duckdb    — BigData (DuckDBTable)
    list      — python-список

ПРОВЕРКА ТИПА:

    t1 = type(42)          # "integer"
    t2 = type(3.14)        # "float"
    t3 = type("abc")       # "string"
    t4 = type(true)        # "boolean"
    t5 = type(None)        # "null"
    t6 = type([1, 2, 3])   # "vector"
    t7 = type(["A"; 1])    # "matrix"

ПРИМЕР:

    t1 = type(42)
    t2 = type(3.14)
    t3 = type("abc")
    t4 = type(true)
    t5 = type(None)
    t6 = type([1, 2, 3])
    t7 = type(["A"; 1])

    print(t1)
    print(t2)
    print(t3)
    print(t4)
    print(t5)
    print(t6)
    print(t7)

ВЫВОД:

    integer
    float
    string
    boolean
    null
    vector
    matrix

ВАЖНО:
    null и nan — запрещённые литералы. Только None.
    Регистр не важен: none, NONE, None — всё одно и то же.


--------------------------------------------------------------------------------
1.2. Переменные и зарезервированные слова
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Хранить промежуточные значения.

СИНТАКСИС:

    имя = значение

ИМЯ ПЕРЕМЕННОЙ:
    ✅ Латиница, цифры (не первым символом), подчёркивание
    ✅ Начинается с буквы или _
    ❌ Зарезервированные слова

ПРИМЕР:

    x = 42
    name = "Аня"
    flag = true

    print(x)
    print(name)
    print(flag)

ВЫВОД:

    42
    Аня
    true

ЗАРЕЗЕРВИРОВАННЫЕ СЛОВА (нельзя использовать как имена):

    Управляющие:    if, then, else, for, to, do, step, while, break
    Логические:     and, or, not, true, false, None
    Индексация:     all, end, begin, last
    Модификаторы:   before, after, AZ, ZA, inside, ignore,
                    approx, skip, vertical, horizontal, when,
                    title, save, bins, color, xlabel, ylabel,
                    plotly, static
    find:           rows, cols
    matrixmod:      delete, insert, duplicate, clear, keep, swap
    groupby:        by, agg, having
    Режимы:         BigData, Table
    Агрегаты:       count, sum, min, max, avg
    Ошибки:         try, catch, error
    Графики:        chart, bar, line, pie, hist, scatter, box,
                    heatmap, pair
    Отчёты:         report, report_section, report_text,
                    report_table, report_chart, report_save,
                    report_show, report_save_pdf

ОШИБКИ:

    ❌  count = 0
    ❌  sum = 10
    ❌  rows = [2, 4]
    ❌  error = 5

РЕКОМЕНДУЕМЫЕ ЗАМЕНЫ:

    count  → cnt (или k)
    sum    → total
    min    → mn
    max    → mx
    avg    → avg_val
    rows   → r
    cols   → c
    error  → err

ОСОБАЯ ПЕРЕМЕННАЯ error:
    error — встроенная переменная с текстом последней ошибки.
    Только для чтения. error = 5 — ошибка RESERVED_WORD.
    После успешного выполнения error = None.
    После упавшего — error = текст ошибки.

1.3. Операторы и приоритет
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Выполнять арифметику, сравнения, логику.

ПРИОРИТЕТ (от высшего к низшему):

    ^            Возведение в степень
    - (унарный)  Отрицание
    * / % //     Умножение, деление, остаток, целое деление
    + -          Сложение, вычитание
    == != < > <= >=   Сравнения
    not          Логическое НЕ
    and          Логическое И
    or           Логическое ИЛИ

ПРИМЕР:

    a = 10
    b = 3

    print(a + b)      # 13
    print(a - b)      # 7
    print(a * b)      # 30
    print(a / b)      # 3.3333333333333335
    print(a // b)     # 3
    print(a % b)      # 1
    print(a ^ b)      # 1000

ВЫВОД:

    13
    7
    30
    3.3333333333333335
    3
    1
    1000

СМЕШИВАНИЕ ТИПОВ:

    r1 = 5 + 3           # 8
    r2 = "A" + "B"       # "AB"
    r3 = 5 + "текст"     # "5текст"
    r4 = "A" + 10        # "A10"

ДЕЛЕНИЕ НА НОЛЬ:

    r = 10 / 0           # inf (не ошибка)

ВАЖНО:
    =  — присваивание
    == — сравнение

    ❌  if x = 5 then         # ошибка IF_ASSIGN_IN_CONDITION
    ✅  if x == 5 then


--------------------------------------------------------------------------------
1.4. IF–THEN–ELSE
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Выполнять разные действия в зависимости от условия.

СИНТАКСИС:

    if условие then
    {
        команды_если_истина
    }
    else
    {
        команды_если_ложь
    }

else — опционально. В языке НЕТ elif — используйте вложенные if.

ПРИМЕР:

    x = 10

    if x > 5 then
    {
        r = "x больше 5"
    }
    else
    {
        r = "x не больше 5"
    }

    print(r)

ВЫВОД:

    x больше 5

ВАЖНО:
    Скобки { } — обязательны для блока команд.
    Одна команда может быть без скобок, но лучше всегда ставить.


--------------------------------------------------------------------------------
1.5. Цикл FOR
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Повторить действие заданное число раз или обойти матрицу.

СИНТАКСИС:

    for i = начало to конец do
    {
        команды
    }

    for i = начало to конец step S do
    {
        команды
    }

Если начало <= конца — идём ВВЕРХ.
Если начало > конца — идём ВНИЗ.
step — опциональный (по умолчанию 1).

ПРИМЕР:

    for i = 1 to 5 do
    {
        print(i)
    }
    # 1 2 3 4 5

    for i = 5 to 1 do
    {
        print(i)
    }
    # 5 4 3 2 1

    for i = 2 to 10 step 2 do
    {
        print(i)
    }
    # 2 4 6 8 10

ОБХОД МАТРИЦЫ:

    m = ["Имя", "Возраст"; "Аня", 25; "Боб", 30]

    for i = 2 to lenrow(m) do
    {
        print(m[i, "Имя"], "-", m[i, "Возраст"])
    }
    # Аня - 25
    # Боб - 30

ВАЖНО:
    ❌  for i(1:5) — устаревший синтаксис (ошибка FOR_OLD_SYNTAX)
    ✅  for i = 1 to 5 do
    ❌  for i = 1 to end do — ошибка FOR_END_KEYWORD
    ✅  for i = 1 to lenrow(m) do


--------------------------------------------------------------------------------
1.6. Цикл WHILE
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Повторять, пока условие истинно.

СИНТАКСИС:

    while условие
    {
        команды
    }

ПРИМЕР:

    i = 1
    while i <= 5
    {
        print(i)
        i = i + 1
    }
    # 1 2 3 4 5

    i = 1
    while true
    {
        print(i)
        if i >= 5 then
        {
            break
        }
        i = i + 1
    }
    # 1 2 3 4 5

ВАЖНО:
    Внутри цикла должен быть код, меняющий условие.
    ❌  while i = 5 — ошибка WHILE_ASSIGN_IN_CONDITION
    ❌  while end — ошибка WHILE_END_KEYWORD


--------------------------------------------------------------------------------
1.7. BREAK
--------------------------------------------------------------------------------

2.1. Матрица: что это и зачем
--------------------------------------------------------------------------------

Матрица — таблица с данными. Первая строка — заголовки. Остальные строки — данные.

ЗАЧЕМ:

    m = ["Имя", "Возраст", "Отдел";

    Боб   30       HR
    Вера  17       IT

    ✅  [1, 2; 3, 4]

2.4. Создание векторов: все способы

СПОСОБ 2. vector(N) — вектор из N None

СПОСОБ 3. zeros(N) — вектор из нулей

СПОСОБ 4. ones(N) — вектор из единиц

--------------------------------------------------------------------------------
2.5. Индексация и правило заголовка
--------------------------------------------------------------------------------

⚠️  ИНДЕКСАЦИЯ С 1.
    m[1, :] — это строка ЗАГОЛОВКОВ.

МАТРИЦА (2D):

    m[2, 3]              — ячейка (строка 2, столбец 3)
    m[2, :]              — вся строка 2
    m[:, 3]              — весь столбец 3
    m[2:4, :]            — диапазон строк
    m[:, 2:4]            — диапазон столбцов
    m[end, :]            — последняя строка
    m[:, end]            — последний столбец
    m[end-1, :]          — предпоследняя строка
    m[:, end-1]          — предпоследний столбец
    m[last 3, :]         — последние 3 строки
    m[:, last 2]         — последние 2 столбца
    m[:, "Имя"]          — столбец с заголовком "Имя"
    m["Аня", :]          — строка, где первый столбец = "Аня"

ВЕКТОР (1D):

    v[2]                 — второй элемент
    v[2:4]               — диапазон
    v[end]               — последний
    v[last 2]            — последние 2

ПРАВИЛО ЗАГОЛОВКА:

    по имени (строка)      → заголовок защищён
    по номеру / end / last → заголовок участвует
    явный диапазон [2:end] → заголовок НЕ участвует

    m[:, "Имя"]              # все строки, кроме заголовка
    m[:, 3]                  # все строки, включая заголовок
    m[2:end, "Имя"]          # явный диапазон: со 2-й строки
    m[last 3, "Имя"]         # 3 последние строки данных

ОШИБКИ ИНДЕКСАЦИИ:

    ❌  s[]                    → EMPTY_INDEX
    ❌  s[, "Пол"]             → EMPTY_INDEX_FIRST
    ❌  s[2, ]                 → EMPTY_INDEX_SECOND
    ❌  s[2; 3]                → SEMICOLON_IN_INDEX
    ❌  s(:,"Пол")             → EXPECTED_LBRACKET
    ❌  s[last 2, 1)           → MISSING_RBRACKET
    ❌  s[column "Пол"]        → COLUMN_IN_PROGRAMMER_INDEX
    ❌  s[row 2]               → ROW_IN_PROGRAMMER_INDEX
    ❌  [[1, 2], [3, 4]]       → NESTED_BRACKETS


--------------------------------------------------------------------------------
2.6. Диапазоны и all
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Взять группу строк или столбцов.

ОБОЗНАЧЕНИЯ:

    :               — все строки/столбцы (то же, что all)
    all             — все строки/столбцы (для читаемости)
    2:5             — с 2 по 5 включительно
    3:end           — с 3 до последней
    1:4             — с 1 по 4
    last 10         — последние 10
    end-2           — третья с конца
    end+1           — только в присваивании

ПРИМЕРЫ:

    m[3:end, :]         — строки с 3-й до последней
    m[1:4, :]           — строки с 1-й по 4-ю
    m[last 10, :]       — последние 10 строк
    m[end-2, :]         — третья с конца
    m[:, 3:end]         — столбцы с 3-го до последнего
    m[:, last 2]        — последние 2 столбца
    m[3:end, "Имя"]     — строки с 3-й до конца, столбец "Имя"

ЗАПРЕЩЁННЫЕ ФОРМЫ:

    end:end              — пиши "end"
    end-1:end-1          — пиши "end-1"
    end-4:end            — пиши "last 5"
    end-N:5 / 5:end-N    — нельзя
    last N:end           — нельзя
    2:last N             — нельзя
    end+N при ЧТЕНИИ     — разрешено только при ЗАПИСИ
    last N, где N >= len — ошибка

--------------------------------------------------------------------------------

ЗАЧЕМ:

СИНТАКСИС:

--------------------------------------------------------------------------------
3.7. round, int, frac, frac_digits
--------------------------------------------------------------------------------

round(x [, знаков])   — округление
int(x)                — целая часть
frac(x [, знаков])    — дробная часть
frac_digits(x)        — дробная часть как целое

ПРИМЕР:

    r1 = round(3.14159)       # 3
    r2 = round(3.14159, 2)    # 3.14
    r3 = int(3.7)             # 3
    r4 = int(-3.7)            # -3
    r5 = frac(3.7)            # 0.7
    r6 = frac(3.14159, 2)     # 0.14
    r7 = frac_digits(3.456)   # 456

ВЕКТОР:

    v = [3.7, -2.5, 1.234, 10.0]
    print(round(v))    # [4, -2, 1, 10]
    print(int(v))      # [3, -2, 1, 10]


--------------------------------------------------------------------------------
3.8. Обнуление матрицы: цикл vs функция
--------------------------------------------------------------------------------

ЦИКЛ (сложно):

    m = ["A", "B"; 1, 2; 3, 4]

    for i = 1 to lenrow(m) do
    {
        for j = 1 to lencol(m) do
        {
            m[i, j] = 0
        }
    }
    print(m)

ФУНКЦИЯ (просто):

    m = ["A", "B"; 1, 2; 3, 4]
    m[all, all] = 0
    print(m)

ВЫВОД (одинаковый):

    0 0
    0 0
    0 0


--------------------------------------------------------------------------------
3.9. Арифметика с None
--------------------------------------------------------------------------------

ПРАВИЛО:
    None в любом операнде → None в результате.
    Деление на 0 → None (в векторах) или inf (в скалярах).

    [1, None, 3] + [10, 20, 30]    # [11, None, 33]
    [10, 20, 30] / [2, 0, 5]       # [5.0, None, 6.0]
    10 / 0                          # inf

--------------------------------------------------------------------------------
4.1. filterif: оставить строки по условию
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Оставить только те строки, где условие истинно.
    Аналог Excel: автофильтр. Аналог SQL: WHERE.

СИНТАКСИС:

    r = filterif(условие)

ПРИМЕР:

    m = ["Имя", "Отдел", "Зарплата";
         "Аня", "IT", 85000;
         "Боб", "HR", 65000;
         "Света", "IT", 95000;
         "Гоша", "Sales", 80000]

    r = filterif(m[:, "Отдел"] == "IT")
    print(r)

МАТРИЦА ДО:

    Имя    Отдел  Зарплата
    Аня    IT     85000
    Боб    HR     65000
    Света  IT     95000
    Гоша   Sales  80000

МАТРИЦА ПОСЛЕ:

    Имя    Отдел  Зарплата
    Аня    IT     85000
    Света  IT     95000

СОСТАВНЫЕ УСЛОВИЯ:

    r1 = filterif(m[:, "Отдел"] == "IT" and m[:, "Зарплата"] > 80000)
    r2 = filterif(m[:, "Отдел"] == "IT" or m[:, "Отдел"] == "HR")
    r3 = filterif(not (m[:, "Отдел"] == "IT"))

МОДИФИКАТОРЫ:

    r1 = filterif(m[:, "Имя"] == "ан", inside)
    r2 = filterif(m[:, "Имя"] == "аня", ignore)
    r3 = filterif(m[:, "Имя"] == "ан", inside, ignore)

ВАЖНО:
    Заголовок сохраняется всегда.
    Порядок строк сохраняется.
    Сравнение строк регистрозависимо.
    Функция в условии — ошибка.
    Обход: addcolumn + filterif.

    m = ["Имя", "Отдел", "Зарплата";
         "Аня", "IT", 85000;
         "Боб", "HR", 65000;

МАТРИЦА ПОСЛЕ:

    Имя   Отдел  Зарплата
    Боб   HR     65000

УДАЛЕНИЕ СТРОКИ:

    m = ["A", "B", "C"; 1, 2, 3; 4, 5, 6; 7, 8, 9]

ВЫВОД:

    A  B  C

УДАЛЕНИЕ СТОЛБЦА:

    r = delete(m[3:end, :])

--------------------------------------------------------------------------------
5.1. sort
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Упорядочить строки по столбцу.

СИНТАКСИС:

    r = sort(m[:, "X"], AZ)     # возрастание
    r = sort(m[:, "X"], ZA)     # убывание

ПРИМЕР:

    m = ["Имя", "Возраст"; "Света", 28; "Аня", 25; "Боб", 32]

    r1 = sort(m[:, "Возраст"], AZ)
    print(r1)

ВЫВОД:

    Имя    Возраст
    Аня    25
    Света  28
    Боб    32

ВАЖНО:
    sort НЕ изменяет исходную.
    По имени — заголовок защищён.
    По номеру — заголовок участвует.
    sort(m, AZ) — ошибка SORT_BAD_FIRST_ARG.


--------------------------------------------------------------------------------
5.2. find
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Найти координаты, строки или столбцы по условию.

СИНТАКСИС:

    r1 = find(условие)               # координаты [[строка, столбец], ...]
    r2 = find(условие, rows)         # номера строк
    r3 = find(условие, cols)         # номера столбцов

ПРИМЕР:

    m = ["Имя", "Отдел", "Возраст";
         "Аня", "IT", 25;
         "Боб", "HR", 32;
         "Света", "IT", 28]

    r1 = find(m[:, "Отдел"] == "IT")
    print(r1)

ВЫВОД:

    Строка  Столбец
    2       2
    4       2

    r2 = find(m[:, "Отдел"] == "IT", rows)
    print(r2)    # [2, 4]

    r3 = find(m[:, "Отдел"] == "IT", cols)
    print(r3)    # [2]

МОДИФИКАТОРЫ:

    find(m[:, "Имя"] == "ов", inside)
    find(m[:, "Имя"] == "аня", ignore)
    find(m[:, "Имя"] == "ов", inside, ignore)

ВАЖНО:
    find(..., rows, cols) — ошибка FIND_BAD_SYNTAX.
    Координаты С УЧЁТОМ заголовка (совпадение в первой строке → 2).


--------------------------------------------------------------------------------
5.3. vlookup
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Аналог ВПР: найти значение в справочнике и вернуть из другой колонки.

СИНТАКСИС:

    r = vlookup(где_искать, что_искать, что_возвращать)

ПРИМЕР:

    a = ["ID", "Имя", "Отдел";
         101, "Аня", "IT";
         102, "Боб", "HR";
         103, "Света", "IT"]

    b = ["ID", "Сумма";
         101, 5000;
         103, 7000;
         102, 3000]

    r = vlookup(a[:, "ID"], 101, a[:, "Отдел"])
    print(r)    # IT

    b[:, end+1] = vlookup(a[:, "ID"], b[:, "ID"], a[:, "Отдел"])
    print(b)

МАТРИЦА b ПОСЛЕ:

    ID   Сумма  None
    101  5000   IT
    103  7000   IT
    102  3000   HR

МНЕМОНИКА:

    vlookup(где, что, вернуть)
             a    b      a

    1-й и 3-й — из одной таблицы (справочник).
    2-й — из любой таблицы (источник запроса).

ВАЖНО:
    Строки — без учёта регистра.
    Числа — с приведением типов (101 == "101").
    При дубликатах — первое совпадение.
    Не найдено — None.


--------------------------------------------------------------------------------
5.4. index — алиас find
--------------------------------------------------------------------------------

    r1 = index(m[:, "Отдел"] == "IT")
    r2 = index(m[:, "Отдел"] == "IT", rows)

Работает так же, как find.

--------------------------------------------------------------------------------
6.1. case
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Заменить значения по условию (например, возраст → категория).

СИНТАКСИС:

    r = case(срез,
             when условие1 then значение1,
             when условие2 then значение2,
             else значение_по_умолчанию)

ПРИМЕР:

    m = ["Имя", "Возраст";
         "Аня", 25;
         "Боб", 15;
         "Света", 32]

    r = case(m[:, "Возраст"],
             when < 18 then "Дитя",
             when < 30 then "Молодой",
             else "Взрослый")

    print(r)

ВЫВОД:

    Молодой Дитя Взрослый

ПРИСВАИВАНИЕ В СТОЛБЕЦ:

    m[:, "Категория"] = case(m[:, "Возраст"],
                             when < 18 then "Дитя",
                             else "Взрослый")
    print(m)

МАТРИЦА ПОСЛЕ:

    Имя    Возраст  Категория
    Аня    25       Взрослый
    Боб    15       Дитя
    Света  32       Взрослый

ВАЖНО:
    case на Matrix возвращает ВЕКТОР.
    Внутри when НЕ указывается столбец:
        ✅  when < 18 then "Дитя"
        ❌  when m[:, "Возраст"] < 18 then "Дитя"
    Без else всё, что не подошло → None.
    Операторы: < > <= >= == !=


--------------------------------------------------------------------------------
6.2. applyif
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Изменить часть ячеек в столбце по условию.

СИНТАКСИС:

    r = applyif(условие, m[:, "X"] = значение)

ПРИМЕР:

    m = ["Имя", "Отдел", "Статус";
         "Аня", "IT", "";
         "Боб", "HR", "";
         "Света", "IT", ""]

    r = applyif(m[:, "Отдел"] == "IT", m[:, "Статус"] = "VIP")
    print(r)

МАТРИЦА ПОСЛЕ:

    Имя    Отдел  Статус
    Аня    IT     VIP
    Боб    HR     None
    Света  IT     VIP

ВАЖНО:
    Меняет ТОЛЬКО указанный столбец.
    Где условие ложно — оставляет как было.
    Float-результаты округляются до 4 знаков.
    ✅  applyif(усл, m[:, "X"] = "VIP")
    ❌  applyif(усл, "VIP") — ошибка APPLYIF_BAD_TARGET


--------------------------------------------------------------------------------
6.3. case vs цикл
--------------------------------------------------------------------------------

ЗАДАЧА: возраст → категория.

ЦИКЛОМ:

    m = ["Имя", "Возраст"; "Аня", 25; "Боб", 15; "Света", 32]
    m[:, "Категория"] = 0

    for i = 2 to lenrow(m) do
    {
        v = m[i, "Возраст"]
        if v < 18 then
        {
            m[i, "Категория"] = "Дитя"
        }
        else
        {
            m[i, "Категория"] = "Взрослый"
        }
    }
    print(m)

C CASE:

    m = ["Имя", "Возраст"; "Аня", 25; "Боб", 15; "Света", 32]
    m[:, "Категория"] = case(m[:, "Возраст"],
                             when < 18 then "Дитя",
                             else "Взрослый")
    print(m)

ВЫВОД (одинаковый):

    Имя    Возраст  Категория
    Аня    25       Взрослый
    Боб    15       Дитя
    Света  32       Взрослый

7.1. sum / min / max / avg / median / std / count
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:

ДВА РЕЖИМА:
    Без by — СКАЛЯР (по всей таблице).

ПРИМЕР:

    m = ["Отдел", "Зарплата";
         "IT", 85000;
         "HR", 65000;
         "IT", 95000;
         "Sales", 80000;
         "HR", 72000;
         "IT", 78000]

    s = sum(m[:, "Зарплата"])
    a = avg(m[:, "Зарплата"])
    mn = min(m[:, "Зарплата"])
    mx = max(m[:, "Зарплата"])

    print(s)
    print(a)
    print(mn)
    print(mx)
    print(md)
    print(cnt)

ВЫВОД:

    473000
    78833.33333333333
    65000
    95000
    78000
    6

7.2. Режим с by
--------------------------------------------------------------------------------

    s = sum(m[:, "Зарплата"], by m[:, "Отдел"])
    print(s)    # [258000, 137000, 80000]

    k = count(by m[:, "Отдел"])
    print(k)    # [3, 2, 1]

ВАЖНО:
    sum/min/max/avg/median/std БЕЗ аргумента — ошибка.
    count() БЕЗ аргумента разрешён (считает строки).

7.3. Поведение None

    m = ["Отдел", "Зарплата";

    print(count(m[:, "Зарплата"]))    # 4 (непустых)

--------------------------------------------------------------------------------
8.1. sumif / countif / avgif / minif / maxif / medianif
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Считать агрегат только по строкам, удовлетворяющим условию.

СИНТАКСИС:

    sumif(усл, срез)
    sumif(by m[:, "X"], срез)
    countif(усл)
    countif(by m[:, "X"])
    avgif / minif / maxif / medianif

ПРИМЕР:

    m = ["Отдел", "Зарплата";
         "IT", 85000;
         "HR", 65000;
         "IT", 95000;
         "Sales", 80000;
         "IT", 70000;
         "HR", 72000]

    r1 = sumif(m[:, "Отдел"] == "IT", m[:, "Зарплата"])
    r2 = countif(m[:, "Отдел"] == "IT")
    r3 = avgif(m[:, "Отдел"] == "IT", m[:, "Зарплата"])
    r4 = minif(m[:, "Отдел"] == "IT", m[:, "Зарплата"])
    r5 = maxif(m[:, "Отдел"] == "IT", m[:, "Зарплата"])

    print(r1)    # 250000
    print(r2)    # 3
    print(r3)    # 83333.33333333333
    print(r4)    # 70000
    print(r5)    # 95000

С BY:

    r = sumif(by m[:, "Отдел"], m[:, "Зарплата"])
    print(r)    # [250000, 137000, 80000]

    r = countif(by m[:, "Отдел"])
    print(r)    # [3, 2, 1]

С AND/OR/NOT:

    r1 = avgif(m[:, "Отдел"] == "IT" and m[:, "Возраст"] > 26, m[:, "Зарплата"])
    r2 = minif(m[:, "Отдел"] == "IT" or m[:, "Отдел"] == "HR", m[:, "Зарплата"])

ВАЖНО:
    = в условии — ошибка SUMIF_ASSIGN_IN_CONDITION.
    Без by — скаляр.
    С by — вектор длины = число строк.

ЧАСТЬ 9. ГРУППИРОВКА И СВОДНЫЕ ТАБЛИЦЫ

--------------------------------------------------------------------------------
9.1. groupby
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Аналог SQL GROUP BY — сводка по значению ключа.

СИНТАКСИС:

    r = groupby(by m[:, "X"], agg sum(m[:, "Y"]))
    r = groupby(by m[:, "X"], agg sum(m[:, "Y"]), avg(m[:, "Y"]), count())
    r = groupby(by m[:, "X"], agg sum(m[:, "Y"]), having sum(m[:, "Y"]) > 100000)

ПРИМЕР:

    m = ["Отдел", "Зарплата";
         "IT", 80000;
         "IT", 95000;
         "HR", 60000;
         "HR", 72000;
         "Sales", 88000]

    r = groupby(by m[:, "Отдел"], agg sum(m[:, "Зарплата"]))
    print(r)

МАТРИЦА ПОСЛЕ:

    Отдел  Сумма_Зарплата
    IT     175000
    HR     132000
    Sales  88000

НЕСКОЛЬКО АГРЕГАТОВ:

    r = groupby(by m[:, "Отдел"],
                agg sum(m[:, "Зарплата"]),
                    avg(m[:, "Зарплата"]),
                    count())

МАТРИЦА ПОСЛЕ:

    Отдел  Сумма_Зарплата  Среднее_Зарплата  Количество
    IT     175000          87500.0           2
    HR     132000          66000.0           2
    Sales  88000           88000.0           1

HAVING:

    r = groupby(by m[:, "Отдел"],
                agg sum(m[:, "Зарплата"]),
                having sum(m[:, "Зарплата"]) > 100000)

МАТРИЦА ПОСЛЕ:

    Отдел  Сумма_Зарплата
    IT     175000
    HR     132000

АВТОИМЕНА:
    sum(m[:, "Зарплата"])   → "Сумма_Зарплата"
    avg(m[:, "Зарплата"])   → "Среднее_Зарплата"
    count()                 → "Количество"
    min(m[:, "Зарплата"])   → "Минимум_Зарплата"
    max(m[:, "Зарплата"])   → "Максимум_Зарплата"
    median(m[:, "Зарплата"]) → "Медиана_Зарплата"
    std(m[:, "Зарплата"])   → "Отклонение_Зарплата"


--------------------------------------------------------------------------------
9.2. pivot
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Сводная таблица: ключи становятся строками и (опционально) столбцами.

СИНТАКСИС:

    r = pivot(ключ, значения, агрегат)              # один ключ
    r = pivot(ключ1, ключ2, значения, агрегат)      # два ключа

ПРИМЕР (один ключ):

    m = ["Отдел", "Зарплата";
         "IT", 85000;
         "IT", 95000;
         "HR", 65000;
         "HR", 72000]

    r = pivot(m[:, "Отдел"], m[:, "Зарплата"], sum)
    print(r)

МАТРИЦА ПОСЛЕ:

    Отдел  Значение
    IT     180000
    HR     137000

ПРИМЕР (два ключа):

    m = ["Отдел", "Год", "Продажи";
         "IT", 2023, 100000;
         "IT", 2024, 150000;
         "HR", 2023, 50000;
         "HR", 2024, 60000]

    r = pivot(m[:, "Отдел"], m[:, "Год"], m[:, "Продажи"], sum)
    print(r)

МАТРИЦА ПОСЛЕ:

    Отдел  2023    2024
    IT     100000  150000
    HR     50000   60000

АГРЕГАТЫ: sum, avg, count, min, max, median, first, last, std.
Порядок строк/столбцов — по первому появлению.
Пустые ячейки — None.


--------------------------------------------------------------------------------
9.3. groupagg
--------------------------------------------------------------------------------

ТОЛЬКО MATRIX (RAM).

НАЗНАЧЕНИЕ:
    Блочная агрегация с итогами.

СИНТАКСИС:

    r = groupagg(ключ, значения, агрегат [, "ИТОГО"] [, fill | exact])

ПРИМЕР:

    m = ["Клиент", "Сумма";
         "Альфа", 100;
         "", 200;
         "", 300;
         "Бета", 400;
         "", 500]

    r = groupagg(m[:, "Клиент"], m[:, "Сумма"], sum, "ИТОГО")
    print(r)

МАТРИЦА ПОСЛЕ:

    Клиент  Сумма
    Альфа   100
            200
            300
    ИТОГО   600
    Бета    400
            500
    ИТОГО   900

ВАЖНО:
    groupagg режет по ПОРЯДКУ строк, а не по значению.
    Перед groupagg обычно делают sort(m[:, "Ключ"], AZ).

РЕЖИМЫ:
    fill  — пустые (None, "") присоединяются к текущему блоку (по умолчанию).
    exact — каждое значение — отдельный блок (даже пустое).


--------------------------------------------------------------------------------
9.4. filldown
--------------------------------------------------------------------------------

ТОЛЬКО MATRIX (RAM).

НАЗНАЧЕНИЕ:
    Заполнить пустые значения вниз предыдущим непустым.

СИНТАКСИС:

    r = filldown(m[:, "X"])
    r = filldown(m[:, "X"], маркер)

ПРИМЕР:

    m = ["Клиент", "Товар";
         "Аня", "Яблоки";
         "", "Груши";
         "", "Сливы";
         "Боб", "Бананы";
         "", "Апельсины"]

    r = filldown(m[:, "Клиент"])
    print(r)

МАТРИЦА ПОСЛЕ:

    Клиент  Товар
    Аня     Яблоки
    Аня     Груши
    Аня     Сливы
    Боб     Бананы
    Боб     Апельсины

С МАРКЕРОМ:

    m = ["Клиент"; "Аня"; "-"; "-"; "Боб"; "-"]

9.5. Сравнение способов группировки
--------------------------------------------------------------------------------

pivot       — по значению (сводка).

groupagg    — по порядку (требует сортировки).

--------------------------------------------------------------------------------
11.1. join
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Соединить две таблицы по ключу (аналог SQL JOIN / ВПР).

СИНТАКСИС:

    join(m1, m2, on "ID")
    join(m1, m2, on "ID", how "left")
    join(m1, m2, on ["ID", "Дата"])
    join(m1, m2, on "ID" == "Код")
    join(m1, m2, on "ID", suffixes ["_1", "_2"])

ПРИМЕР:

    m1 = ["ID", "Имя"; 1, "Аня"; 2, "Боб"; 3, "Вера"]
    m2 = ["ID", "Зарплата"; 1, 50000; 2, 60000]

    r = join(m1, m2, on "ID")
    print(r)

МАТРИЦА ПОСЛЕ (LEFT):

    ID  Имя   Зарплата
    1   Аня   50000
    2   Боб   60000
    3   Вера  None


--------------------------------------------------------------------------------
11.2. Режимы how
--------------------------------------------------------------------------------

    "left"  — все строки левой + совпадения (по умолчанию)
    "inner" — только совпадения
    "right" — все строки правой
    "outer" — все строки обеих

ПРИМЕР INNER:

    r = join(m1, m2, on "ID", how "inner")
    print(r)

МАТРИЦА ПОСЛЕ:

    ID  Имя  Зарплата
    1   Аня  50000
    2   Боб  60000


--------------------------------------------------------------------------------
11.3. Сложные ключи и суффиксы
--------------------------------------------------------------------------------

НЕСКОЛЬКО КЛЮЧЕЙ:

    r = join(m1, m2, on ["ID", "Дата"])

РАЗНЫЕ ИМЕНА:

    r = join(m1, m2, on "ID" == "Код")

СУФФИКСЫ:

    r = join(m1, m2, on "ID", suffixes ["_1", "_2"])

ВАЖНО:
    join требует ДВЕ таблицы + on.
    При конфликте имён автоматически добавляет суффиксы.
    На DuckDB работает через SQL — быстро на миллионах строк.

--------------------------------------------------------------------------------
14.1. date
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Конвертировать формат даты.

СИНТАКСИС:

    date(данные, "вход", "выход")

ПРИМЕР:

    r1 = date("20.06.2025", "DD.MM.YYYY", "DD MMMM YYYY")
    # "20 июня 2025"

    r2 = date("06/20/2025", "MM/DD/YYYY", "DD.MM.YYYY")
    # "20.06.2025"

    r3 = date("2025-06-20", "YYYY-MM-DD", "DD.MM.YYYY")
    # "20.06.2025"

ТОКЕНЫ:
    YYYY — год 4 цифры
    YY   — год 2 цифры
    MM   — месяц 2 цифры
    M    — месяц 1-2 цифры
    MMMM — месяц словом
    MMM  — месяц кратко
    DD   — день 2 цифры
    D    — день 1-2 цифры
    HH   — часы 24ч
    hh   — часы 12ч
    MM после HH — минуты
    SS   — секунды
    AM/PM — маркер дня

14.2. DateDiff
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    Разница между датами.

СИНТАКСИС:

    DateDiff(d1, d2, "формат", "единица")

ЕДИНИЦЫ: seconds, minutes, hours, days, weeks, months, years, all.

ПРИМЕР:

    r1 = DateDiff("20.06.2024", "25.06.2024", "DD.MM.YYYY", "days")     # 5
    r2 = DateDiff("01.01.2025", "01.01.2026", "DD.MM.YYYY", "years")    # 1
    r3 = DateDiff("01.01.2025", "01.02.2025", "DD.MM.YYYY", "months")   # 1
    r4 = DateDiff("20.06.2024", "25.06.2024", "DD.MM.YYYY", "all")
    # "5 дней"

ВАЖНО:
    Считаются ПОЛНЫЕ прошедшие периоды.
    Если не хватает хотя бы дня — период не полный.

--------------------------------------------------------------------------------
16.1. abc
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:
    ABC-анализ (Парето 80/20).

ПРИМЕР:

    m = ["Товар", "Продажи";
         "A", 100;
         "B", 300;
         "C", 600]

    r = abc(m[:, "Продажи"])
    print(r)

МАТРИЦА ПОСЛЕ:

    Товар  Продажи  __abc
    A      100      C
    B      300      B
    C      600      A

С ПРОЦЕНТАМИ:

    r = abc(m[:, "Продажи"], %)
    print(r)

МАТРИЦА ПОСЛЕ:

    Товар  Продажи  __abc  __share
    A      100      C      10.0
    B      300      B      30.0
    C      600      A      60.0

ПРАВИЛА:
    Пороги по умолчанию 80 / 95.
    Пороги автосортируются: 90, 70 → 70, 90.
    % — проценты (0-100), округление 2 знака.
    coef — коэффициент (0.0-1.0), округление 4 знака.
    Целевой столбец — m[:, N] или m[:, "Имя"] или m[:, end+1].
    __abc вставляется СПРАВА от исходного среза.
    Порядок строк сохраняется.

16.3. anomaly
--------------------------------------------------------------------------------

НАЗНАЧЕНИЕ:

--------------------------------------------------------------------------------
19.1. Что такое BigData
--------------------------------------------------------------------------------

Matrix — данные в RAM. Быстро, но ограничено размером памяти.
DuckDB — данные на диске (BigData). До 1 млрд строк.
Но DuckDB — read-only view на файл. Часть функций недоступна.

ПРОВЕРКА ТИПА:

    m = OpenCSV("data.csv")
    print(type(m))    # "matrix" или "duckdb"


--------------------------------------------------------------------------------
19.2. ToBigData / ToMatrix
--------------------------------------------------------------------------------

    bd = ToBigData(m)              # Matrix → DuckDB
    m2 = ToMatrix(bd)              # DuckDB → Matrix (вся таблица)
    m3 = ToMatrix(bd, 1000)        # первые 1000 строк

    bd = Convert_Matrix_To_BigData(m)
    m2 = Convert_BigData_To_Matrix(bd)

ВАЖНО:
    Только 2D-матрицы. Вектор → BigData нельзя.
    ToMatrix с большим количеством строк может съесть RAM.


--------------------------------------------------------------------------------
19.3. Что работает на DuckDB
--------------------------------------------------------------------------------

✅ filterif, deleteif, delete, sort, groupby, pivot
✅ addcolumn, addrows, applyif
✅ Unique, CountDistinct, ValueCounts, DeleteDuplicate
✅ replacetext, clean, case, sum/min/max/avg
✅ unpivot, joinarray, sample, ToMatrix, join
✅ rownumber, rank, lag, winsum и другие оконные
✅ printshow, SaveCSV, SaveParquet
✅ abc, percentof, anomaly

19.4. Что работает только на Matrix
--------------------------------------------------------------------------------

❌ insertif
❌ matrixmod
❌ insert
❌ copy
❌ move
❌ groupagg
❌ filldown
❌ transpose

Если получил ошибку <FUNC>_DUCKDB — конвертируй:

ЧАСТЬ 22. ВАЖНЫЕ ПРАВИЛА И ШПАРГАЛКА

--------------------------------------------------------------------------------
22.1. Правила, которые надо запомнить
--------------------------------------------------------------------------------

1. Все функции ВОЗВРАЩАЮТ значение — сохраняйте результат.

2. None — единственный литерал пустого значения.
   Слова null и nan выдадут ошибку.
   Регистр не важен: none, NONE, None — всё одно.

3. = — присваивание, == — сравнение.

4. Логические операторы: and / or / not.

5. random() и range() — только в присваивании.

6. Индексация с 1.

7. m[1, :] — строка заголовков.

8. Заголовок защищён ТОЛЬКО при обращении по имени:
   m[:, "Имя"]    — защищён
   m[:, 3]        — участвует

9. all = : (все строки/столбцы) — для читаемости.

10. DuckDB (BigData) — read-only.
    Не работает: copy, move, insert, insertif,
    matrixmod, groupagg, filldown, transpose.

11. groupagg и filldown — ТОЛЬКО Matrix.

12. case на Matrix возвращает ВЕКТОР:
    m[:, "X"] = case(m[:, "X"], ...)

13. Порядок аргументов в abc, percentof, anomaly — ЛЮБОЙ.
    В остальных функциях — строгий.

14. Имена переменных НЕ регистрозависимы.

--------------------------------------------------------------------------------
22.3. Часто задаваемые вопросы
--------------------------------------------------------------------------------

ВОПРОС: Почему filterif не меняет матрицу?
ОТВЕТ:  Функция возвращает НОВУЮ матрицу. Сохрани: m = filterif(...)

ВОПРОС: Почему m[1, :] — это заголовки?
ОТВЕТ:  Индексация с 1. Первая строка — заголовки.

ВОПРОС: Как обнулить всю матрицу?
ОТВЕТ:  m[all, all] = 0

ВОПРОС: Как добавить столбец?
ОТВЕТ:  m = addcolumn(m, "Имя", значение)
        или m[:, "Имя"] = значение

ВОПРОС: Как добавить строку?
ОТВЕТ:  m[end+1, :] = [...]  или  m = addrows(m, 1)

ВОПРОС: Почему нельзя написать null?
ОТВЕТ:  Только None. null и nan — запрещены.

ВОПРОС: Почему groupagg даёт неправильные итоги?
ОТВЕТ:  Он режет по порядку строк. Сначала sort(m[:, "Ключ"], AZ).

ВОПРОС: Почему case не меняет столбец?
ОТВЕТ:  case возвращает вектор. Присвой: m[:, "X"] = case(m[:, "X"], ...)

ВОПРОС: Почему функция не работает на DuckDB?
ОТВЕТ:  Часть функций только для Matrix.
        Конвертируй: m = ToMatrix(bd).

ВОПРОС: Что такое all?
ОТВЕТ:  Синоним : для читаемости. m[all, "Имя"] = m[:, "Имя"].

ВОПРОС: Что такое None?
ОТВЕТ:  Пустое значение. Регистр не важен: none, NONE, None.

ВОПРОС: Как сохранить отчёт?
ОТВЕТ:  report_save(true) — сохранить и открыть.
        report_save(false) — только сохранить.

ВОПРОС: Как построить график?
ОТВЕТ:  chart(bar, x, y, title "Заголовок")

ВОПРОС: Как сделать сводную?
ОТВЕТ:  groupby(by m[:, "Отдел"], agg sum(m[:, "Зарплата"]))
        pivot(m[:, "Отдел"], m[:, "Год"], m[:, "Продажи"], sum)

ВОПРОС: Как соединить две таблицы?
ОТВЕТ:  join(m1, m2, on "ID")

ВОПРОС: Как найти позицию?
ОТВЕТ:  find(m[:, "Отдел"] == "IT")            — координаты
        find(m[:, "Отдел"] == "IT", rows)      — строки
        find(m[:, "Отдел"] == "IT", cols)      — столбцы

ВОПРОС: Как посчитать сумму по группам?
ОТВЕТ:  sum(m[:, "Зарплата"], by m[:, "Отдел"])   — вектор
        groupby(by ..., agg sum(...))               — сводка

ВОПРОС: Как получить топ-3 в группе?
ОТВЕТ:  qualify(m, rownumber(m, by m[:, "Отдел"],
                            order m[:, "Зарплата"], ZA) <= 3)

ВОПРОС: Как посчитать стаж?
ОТВЕТ:  age(m[:, "Приём"], m[:, "Увольнение")
        age(m[:, "Приём"], m[:, "Увольнение", "all")

ВОПРОС: Как очистить телефон?
ОТВЕТ:  clean(m[:, "Телефон"], "digits")
