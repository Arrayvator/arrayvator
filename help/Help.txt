ВВЕДЕНИЕ
================================================================================

ArrayVator — это язык программирования для работы с таблицами.
Он похож на Excel, но с настоящими циклами, условиями и функциями.

ТАБЛИЦА В ARRAYVATOR НАЗЫВАЕТСЯ МАТРИЦЕЙ.

ГЛАВНОЕ ПРАВИЛО ЯЗЫКА:

    ВСЕ ФУНКЦИИ ВОЗВРАЩАЮТ ЗНАЧЕНИЕ.
    РЕЗУЛЬТАТ НУЖНО СОХРАНИТЬ В ПЕРЕМЕННУЮ.

Правильно:

    r = filterif(m[:, "Отдел"] == "IT")

Неправильно:

    filterif(m[:, "Отдел"] == "IT")

Если не сохранить результат — он потеряется.

ЧТО ЕСТЬ В ЯЗЫКЕ:
    ✅ Подсветка синтаксиса
    ✅ Автодополнение функций
    ✅ Встроенная справка по каждой функции
    ✅ Экспорт программы в EXE (без танцев с бубном)
    ✅ Работа с файлами Excel, CSV, TXT, Parquet, SQLite
    ✅ Работа с 1 млрд строк (BigData)

--------------------------------------------------------------------------------
1.1. ЧТО ТАКОЕ МАТРИЦА
--------------------------------------------------------------------------------

Матрица — это таблица с данными.

ПЕРВАЯ СТРОКА — ЗАГОЛОВКИ СТОЛБЦОВ.
Остальные строки — данные.

    m = ["Имя", "Возраст", "Отдел";
         "Аня", 25, "IT";
         "Боб", 30, "HR";
         "Вера", 17, "IT"]

ПРАВИЛА ЗАПИСИ:
    • Строки разделяются ТОЧКОЙ С ЗАПЯТОЙ  ;
    • Столбцы разделяются ЗАПЯТОЙ  ,
    • Первая строка — заголовки
    • Матрица двумерная (2D)

    print(m)

ВЫВОД:

    Имя   Возраст  Отдел
    Аня   25       IT
    Боб   30       HR
    Вера  17       IT


--------------------------------------------------------------------------------
1.2. ЧТО ТАКОЕ ВЕКТОР
--------------------------------------------------------------------------------

Вектор — это одна строка ИЛИ один столбец значений.
У вектора ОДИН индекс.

    v = [10, 20, 30, 40, 50]
    print(v)

ВЫВОД:

    [10, 20, 30, 40, 50]

ВЗЯТЬ СТОЛБЕЦ ИЗ МАТРИЦЫ (получим вектор):

    m = ["Имя", "Возраст"; "Аня", 25; "Боб", 30]
    v = m[:, "Возраст"]
    print(v)

ВЫВОД:

    [25, 30]

ВЗЯТЬ СТРОКУ ИЗ МАТРИЦЫ (получим вектор):

    v = m[2, :]
    print(v)

ВЫВОД:

    [Аня, 25]


--------------------------------------------------------------------------------
1.3. КАК УЗНАТЬ РАЗМЕР МАТРИЦЫ
--------------------------------------------------------------------------------

    lenrow(m)   — количество строк (включая заголовок)
    lencol(m)   — количество столбцов
    len(v)      — количество элементов вектора


ПРИМЕР:

    m = ["Имя", "Возраст", "Отдел";
         "Аня", 25, "IT";
         "Боб", 30, "HR";
         "Вера", 17, "IT"]

    r = lenrow(m)
    c = lencol(m)

    print(r)
    print(c)

ВЫВОД:

    4
    3


ВАЖНО:
    В матрице 3 строки данных, но lenrow вернул 4,
    потому что заголовок тоже считается строкой!

    Если нужна только длина данных — вычитай 1:

    n = lenrow(m) - 1
    print(n)
    # 3


--------------------------------------------------------------------------------
1.4. КАК ПРИСВОИТЬ ЗНАЧЕНИЕ ЯЧЕЙКЕ
--------------------------------------------------------------------------------

ОДНА ЯЧЕЙКА:
    m[2, 3] = 99

ВСЯ СТРОКА:
    m[2, :] = [10, 20, 30]

ВЕСЬ СТОЛБЕЦ:
    m[:, 2] = [0, 1, 2]

ДИАПАЗОН:
    m[2:4, 2:4] = [1, 2; 3, 4; 5, 6]

ЗАПОЛНИТЬ ОДНИМ ЗНАЧЕНИЕМ:
    m[1, :] = 0         # всю первую строку
    m[:, 2] = 99        # весь второй столбец
    m[2:5, 2:5] = 0     # блок

ПО ИМЕНИ СТОЛБЦА:
    m[:, "Имя"] = ["Аня", "Боб", "Вера"]
    m[2, "Возраст"] = 26


ПРИМЕР:

    m = ["Имя", "Возраст", "Отдел";
         "Аня", 25, "IT";
         "Боб", 30, "HR";
         "Вера", 17, "IT"]

    print("До:")
    print(m)
    print("")

    m[2, 3] = "Программист"

    print("После:")
    print(m)

ВЫВОД:

    До:
    Имя   Возраст  Отдел
    Аня   25       IT
    Боб   30       HR
    Вера  17       IT

    После:
    Имя   Возраст  Отдел
    Аня   25       Программист
    Боб   30       HR
    Вера  17       IT


--------------------------------------------------------------------------------
1.5. КАК ДОБАВИТЬ СТОЛБЕЦ
--------------------------------------------------------------------------------

СПОСОБ 1. Через end+1 (расширение справа)

    m = ["A", "B"; 1, 2]

    m[:, end+1] = None           # добавили пустой столбец
    m[1, end] = "C"              # назвали его "C"
    m[2, end] = 3                # заполнили данными

    print(m)

ВЫВОД:

    A  B  C
    1  2  3


СПОСОБ 2. Через addcolumn (рекомендуется)

    m = ["A", "B"; 1, 2]
    m = addcolumn(m, "C", [3, 4])

    print(m)

ВЫВОД:

    A  B  C
    1  2  3


СПОСОБ 3. Скаляр — одно значение во все ячейки

    m = ["A", "B"; 1, 2; 3, 4]
    m = addcolumn(m, "Год", 2024)

    print(m)

ВЫВОД:

    A  B  Год
    1  2  2024
    3  4  2024


СПОСОБ 4. Выражение из других столбцов

    m = ["A", "B"; 1, 2; 3, 4]
    m = addcolumn(m, "Сумма", m[:, "A"] + m[:, "B"])

    print(m)

ВЫВОД:

    A  B  Сумма
    1  2  3
    3  4  7


СПОСОБ 5. По имени (несуществующий столбец создаётся сам)

    m = ["A", "B"; 1, 2]
    m[:, "Новый"] = [10, 20]

    print(m)

ВЫВОД:

    A  B  Новый
    1  2  10


--------------------------------------------------------------------------------
1.6. КАК ДОБАВИТЬ СТРОКУ
--------------------------------------------------------------------------------

СПОСОБ 1. Через end+1

    m = ["A", "B"; 1, 2]

    m[end+1, :] = [3, 4]

    print(m)

ВЫВОД:

    A  B
    1  2
    3  4


СПОСОБ 2. Через addrows

    m = ["A", "B"; 1, 2]
    m = addrows(m, 1)
    m[end, :] = [3, 4]

    print(m)

ВЫВОД:

    A  B
    1  2
    3  4


СПОСОБ 3. Сразу заполнить

    m = ["A", "B"; 1, 2]
    m = addrows(m, 2, 0)

    print(m)

ВЫВОД:

    A  B
    1  2
    0  0
    0  0


ЗА ПРЕДЕЛАМИ ТАБЛИЦЫ:

    m = ["A", "B"; 1, 2]

    m[5, :] = [10, 20]

    print(m)

ВЫВОД:

    A     B
    1     2
    None  None
    None  None
    10    20


--------------------------------------------------------------------------------
1.7. ИНДЕКСАЦИЯ И ГЛАВНОЕ ПРАВИЛО ЗАГОЛОВКА
--------------------------------------------------------------------------------

⚠️  ИНДЕКСАЦИЯ С 1.

    m[1, :] — это строка ЗАГОЛОВКОВ.

ГЛАВНОЕ ПРАВИЛО ЗАГОЛОВКА:

    ┌──────────────────────────────────────────────────────────────┐
    │  Пишешь ИМЯ (в кавычках) — заголовок НЕ участвует.          │
    │  Пишешь НОМЕР — заголовок УЧАСТВУЕТ.                         │
    └──────────────────────────────────────────────────────────────┘

    m[:, "Имя"]       — заголовок НЕ участвует ✅
    m[:, 3]           — заголовок УЧАСТВУЕТ ⚠️

    m["Аня", :]       — заголовок НЕ участвует ✅
    m[2, :]           — строка 2 (заголовок — это строка 1)

Это правило работает ВЕЗДЕ:
    • при индексации
    • в filterif / deleteif / sort / find
    • во всех функциях

ЗАЧЕМ ТАК:
    Когда ты пишешь m[:, "Имя"], ты хочешь работать с ДАННЫМИ,
    а не с заголовком "Имя". Поэтому заголовок исключается.
    Когда ты пишешь m[:, 3], ты работаешь с ФИЗИЧЕСКИМ столбцом 3,
    и заголовок тоже является частью этого столбца.


--------------------------------------------------------------------------------
1.8. ДИАПАЗОНЫ (настраиваемые)
--------------------------------------------------------------------------------

ArrayVator позволяет брать диапазоны:
    • по номерам:  2:5     (со 2-й по 5-ю)
    • до конца:    3:end   (с 3-й до последней)
    • от начала:   begin:4 (с 1-й по 4-ю)
    • последние N: last 10 (последние 10)
    • с конца:     end-2   (третья с конца)

ЗАЧЕМ ЭТО:
    • Если заголовок занимает НЕСКОЛЬКО строк
    • Если нужно исключить первые строки из расчёта
    • Если нужно взять только последние N строк/столбцов

ПРИМЕРЫ:

    m[3:end, :]         — строки с 3-й до последней (включительно)
    m[begin:4, :]       — строки с 1-й по 4-ю
    m[last 10, :]       — последние 10 строк
    m[end-2, :]         — третья с конца
    m[:, 3:end]         — столбцы с 3-го до последнего
    m[:, last 2]        — последние 2 столбца

    m[3:end, "Имя"]     — строки с 3-й до конца, столбец "Имя"
    m[last 5, 2]        — последние 5 строк, столбец 2

ЗАЧЕМ ИМЕННО ТАК:
    Допустим, в таблице две строки заголовка:

        m = ["ФИО", "Возраст";
             "Имя", "лет";          ← вторая строка заголовка
             "Аня", 25;
             "Боб", 30]

    Тогда m[3:end, :] — строки с данными (без двух заголовков).


СРАВНЕНИЕ:

    m[:, "Имя"]        — все строки, кроме заголовка
    m[:, 3]            — все строки, ВКЛЮЧАЯ заголовок
    m[2:end, "Имя"]    — явно со 2-й строки
    m[3:end, 2]        — с 3-й строки, столбец 2
    m[last 10, 1]      — последние 10 строк, столбец 1


ПРАВИЛО:
    Пишешь имя столбца или строки → заголовок НЕ участвует.
    Пишешь номер / диапазон по номерам → заголовок участвует,
    если ты явно не исключил его через 2:end или 3:end.

--------------------------------------------------------------------------------
2.1. FILTERIF — оставить строки по условию
--------------------------------------------------------------------------------

ЧТО ДЕЛАЕТ:
    Оставляет только те строки, где условие истинно.
    Аналог Excel: автофильтр.
    Аналог SQL:  SELECT * FROM m WHERE условие

СИНТАКСИС:

    r = filterif(условие)

ВАЖНО: результат нужно СОХРАНИТЬ!

    r = filterif(m[:, "Отдел"] == "IT")
    m = filterif(m[:, "Отдел"] == "IT")


ПРИМЕР:

    m = ["Имя", "Отдел", "Зарплата";
         "Аня", "IT", 85000;
         "Боб", "HR", 65000;
         "Света", "IT", 95000;
         "Гоша", "Sales", 80000;
         "Даша", "IT", 70000;
         "Егор", "HR", 72000]

    print("ДО ФУНКЦИИ:")
    print(m)
    print("")

    r = filterif(m[:, "Отдел"] == "IT")

    print("ПОСЛЕ ФУНКЦИИ (r):")
    print(r)

ВЫВОД:

    ДО ФУНКЦИИ:
    Имя    Отдел  Зарплата
    Аня    IT     85000
    Боб    HR     65000
    Света  IT     95000
    Гоша   Sales  80000
    Даша   IT     70000
    Егор   HR     72000

    ПОСЛЕ ФУНКЦИИ (r):
    Имя    Отдел  Зарплата
    Аня    IT     85000
    Света  IT     95000
    Даша   IT     70000


ИСХОДНАЯ m НЕ ИЗМЕНИЛАСЬ — мы сохранили в r.
Для мутации:

    m = filterif(m[:, "Отдел"] == "IT")


СОСТАВНЫЕ УСЛОВИЯ:

    r1 = filterif(m[:, "Отдел"] == "IT" and m[:, "Зарплата"] > 80000)
    r2 = filterif(m[:, "Отдел"] == "IT" or m[:, "Отдел"] == "HR")
    r3 = filterif(not (m[:, "Отдел"] == "IT"))


МОДИФИКАТОРЫ:

    r1 = filterif(m[:, "Имя"] == "ан", inside)          — подстрока
    r2 = filterif(m[:, "Имя"] == "аня", ignore)         — без регистра
    r3 = filterif(m[:, "Имя"] == "ан", inside, ignore)  — оба


ДИАПАЗОНЫ В УСЛОВИИ:

    r = filterif(m[3:end, "Отдел"] == "IT")
    # Смотрим только со 3-й строки (первые 2 строки защищены).

    r = filterif(m[last 10, "Зарплата"] > 80000)
    # Только последние 10 строк.

    r = filterif(m[2:end, "Отдел"] == "IT")
    # Начиная со 2-й строки.


ПРАВИЛО ЗАГОЛОВКА В FILTERIF:

    m[:, "Отдел"]        — заголовок НЕ участвует
    m[:, 2]              — заголовок УЧАСТВУЕТ
    m[3:end, "Отдел"]    — со 3-й строки
    m[last 5, "Отдел"]   — последние 5 строк


ВАЖНО:
    Заголовок сохраняется всегда.
    Порядок строк сохраняется.
    Сравнение строк регистрозависимо: "IT" ≠ "it".


ФУНКЦИЯ В УСЛОВИИ — НЕЛЬЗЯ:

    ❌  r = filterif(year(m[:, "Дата"]) == 2025)
        → ошибка FILTERIF_FUNCTION_IN_CONDITION

РЕШЕНИЕ:

    m2 = addcolumn(m, "Год", year(m[:, "Дата"]))
    r = filterif(m2[:, "Год"] == 2025)


--------------------------------------------------------------------------------
2.2. DELETEIF — удалить строки по условию
--------------------------------------------------------------------------------

ЧТО ДЕЛАЕТ:
    Удаляет строки, где условие ИСТИННО.

    deleteif(условие) = filterif(НЕ условие)

СИНТАКСИС:

    r = deleteif(условие)


ПРИМЕР:

    m = ["Имя", "Отдел", "Зарплата";
         "Аня", "IT", 85000;
         "Боб", "HR", 65000;
         "Света", "IT", 95000;
         "Гоша", "Sales", 80000;
         "Даша", "IT", 70000;
         "Егор", "HR", 72000]

    print("ДО ФУНКЦИИ:")
    print(m)
    print("")

    r = deleteif(m[:, "Отдел"] == "IT")

2.4. ПОЧЕМУ IF-ФУНКЦИИ ЛУЧШЕ ЦИКЛА

ЗАДАЧА: оставить только IT-строки.

С ЦИКЛОМ (8+ строк кода):

            r[lenrow(r), "Имя"] = m[i, "Имя"]

    }

    print(r)

    Аня   IT

    Аня   IT
    Вера  IT


СЛОЖНОЕ УСЛОВИЕ — С ЦИКЛОМ:

         "Аня", "IT", 25, 85000;
         "Боб", "HR", 32, 65000;
         "Света", "IT", 28, 95000;
         "Гоша", "Sales", 41, 80000;
         "Даша", "IT", 35, 88000]

    for i = 2 to lenrow(m) do
    {
        if (m[i, "Отдел"] == "IT" and m[i, "Возраст"] > 26)
           or (m[i, "Отдел"] == "HR" and m[i, "Возраст"] < 30)
        then

            r[lenrow(r), "Отдел"] = m[i, "Отдел"]
            r[lenrow(r), "Возраст"] = m[i, "Возраст"]
            r[lenrow(r), "Зарплата"] = m[i, "Зарплата"]
        }
    }

    250000

    s = 0
    for i = 2 to lenrow(m) do

        if (m[i, "Отдел"] == "IT" and m[i, "Зарплата"] > 80000)
           or (m[i, "Отдел"] == "HR" and m[i, "Зарплата"] < 70000)
        then
        {
            s = s + m[i, "Зарплата"]
        }
    }

    s = sumif(
        (m[:, "Отдел"] == "IT" and m[:, "Зарплата"] > 80000) or

        m[:, "Зарплата"]
    )
    print(s)

    r = abc(m[:, "Продажи"], %, m[:, 3])

--------------------------------------------------------------------------------
12.1. ГЛАВНЫЕ ПРАВИЛА
--------------------------------------------------------------------------------

1. Все функции ВОЗВРАЩАЮТ значение — сохраняйте результат:

       m = filterif(m[:, "Отдел"] == "IT")
       r = sort(m[:, "Имя"], AZ)

2. None — единственный литерал пустого значения.
   null и nan — ошибка.

3. =  — присваивание. == — сравнение.

4. Логические: and / or / not  (не &&, ||, !).

5. random() — только в присваивании.

6. range() / Number() — только в присваивании.

7. ЗАГОЛОВОК:
       по имени (m[:, "X"])   → НЕ участвует
       по номеру (m[:, 3])    → УЧАСТВУЕТ
       диапазон (m[3:end])    → как указано
       last N                 → последние N

8. Функции, требующие присваивания:
       filterif, deleteif, sort, case, applyif,
       abc, percentof, anomaly, sumif, countif, avgif,
       minif, maxif, medianif, countuniqueif, sumproduct,
       find, vlookup, pivot, groupby,
       rownumber, rank, denserank, lag, lead, winsum, ...

9. Функции, НЕ требующие присваивания:
       print, println, printshow, chart,
       report, report_section, report_text,
       report_table, report_chart, report_save,
       report_show, report_save_pdf,
       LogToFile, LogOff

10. Имена переменных НЕ регистрозависимы.

11. Индексация С 1.

12. DuckDB (BigData) — read-only.
    Не работает: copy, move, insert, insertif,
    matrixmod, groupagg, filldown, transpose.

13. groupagg и filldown — ТОЛЬКО Matrix.

14. case на Matrix возвращает ВЕКТОР.

15. Чем сложнее условие — тем больше выигрыш
    от if-функции (filterif, deleteif, sumif, ...).
